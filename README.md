# anmutu/homebrew-tap

Homebrew tap for [Keyway](https://keyway.one) — the local gateway for AI coding CLIs.

## Install

```bash
brew install --cask anmutu/tap/keyway
```

## Update

```bash
brew upgrade --cask keyway
```

(Keyway also self-updates in-app; `auto_updates` is declared, so brew only manages installs.)
